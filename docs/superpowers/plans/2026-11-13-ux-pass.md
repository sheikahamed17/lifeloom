# UX pass: critique + slop-yardstick fixes (13 Nov 2026)

Source: the 10 Nov Impeccable critique (21/40, 2 P0, 6 P1; `.impeccable/critique/`, PDF in the owner's Downloads) and the "What is slop?" yardstick made binding in PRODUCT.md. Branch `feat/ux-pass`, one commit per band, full gate before each.

Owner decisions (13 Nov): Money home is "Needs you first" (sticky capture bar → Needs-you queue → compact "This month" summary → Entries with one Filter button; full cards one tap deeper on phone, right column on desktop). Dashboard merges into Money home: Accounts, Upcoming, Goals and Owed move; Today's tasks, Habits, Recent activity and Spend trend drop (Tasks tab, Habits page and Analytics already cover them); `/dashboard` redirects. Dark only. Identity (aurora, glass, glow, indigo) stays; each effect gets one job.

## Rules (deck step 2: every don't paired with a do)

- Don't glow every primary button. **Do** glow only the one primary action on screen (`glow-cta`); everything else is flat.
- Don't nest glass or use it as filler. **Do** use `glass` (blurred) for one layer: floating chrome (capture bar, dock, menus, toasts) and top-level section cards; rows inside use `glass-soft`.
- Don't use emoji or unicode glyphs as interface icons. **Do** use Lucide for every control; emoji appear only as user-chosen category/account glyphs, `aria-hidden`.
- Don't use raw Tailwind palette colours (`text-rose-500`, `bg-blue-50`). **Do** use tokens (`destructive`, `income`, `warning`, `accent-2`, `primary`, `muted-foreground`); an ESLint rule enforces it.
- Don't write tiny all-caps labels or 10 px text. **Do** use sentence-case labels at 12 px minimum (`text-xs`).
- Don't add helper text that repeats the obvious ("tap any field to edit"). **Do** make controls look like what they do.
- Don't hide the first real item under summaries. **Do** put what needs the owner first.
- Don't say it twice (Dashboard + Money home, owed amount twice). **Do** give each figure one home.
- Don't show a number without a name or a figure that can't be computed (₹NaN, "+0"). **Do** label every figure and render "—" when it's missing.
- Don't leave a tap going nowhere or ending in silence. **Do** confirm every save and explain every failure.
- Radii: `rounded-2xl` for surfaces, `rounded-lg` for controls, `rounded-full` for badges. Buttons 40 px by default; touch targets `min-h-11`. One date format (`formatDay`).
